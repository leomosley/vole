# Contributing

## Setup

```sh
git clone https://github.com/leomosley/vole.git
cd vole
bun install
```

## Development

Work off the `dev` branch. Open pull requests targeting `dev`, not `main`.

```sh
git checkout dev
git checkout -b your-feature
```

## Commits

Follow [Conventional Commits](https://www.conventionalcommits.org).

Keep pull requests small and focused. CI must pass before merging.
